# Saisie Manuelle des Paramètres

## ✨ Nouvelle Fonctionnalité : Saisie Précise au Clavier

Vous pouvez maintenant **taper directement** les valeurs des paramètres au clavier pour plus de précision !

## 🎯 Comment ça marche

Chaque paramètre a maintenant **deux façons de régler la valeur** :

### 1. Avec le Curseur (comme avant)
- Déplacez le curseur avec la souris
- Parfait pour des ajustements rapides

### 2. Avec le Champ de Saisie (NOUVEAU !)
- **Cliquez dans le champ** à droite du curseur
- **Tapez la valeur** exacte que vous voulez
- **Appuyez sur Entrée** pour valider

## 📐 Les Trois Paramètres

### 1. Taille (mm)
```
[Label] [=========o=====] [25.0]
                           ↑
                    Cliquez ici pour taper
```

**Options :**
- **Curseur** : Glissez de 5 à 100 mm
- **Saisie** : Tapez n'importe quelle valeur entre 5 et 100
- **Flèches** : Cliquez ▲▼ pour ajuster par pas de 1 mm

**Exemples :**
- Tapez `30` pour 30 mm exactement
- Tapez `25.5` pour 25.5 mm
- Tapez `47.3` pour 47.3 mm

### 2. Espacement (mm)
```
[Label] [o=============] [2.5]
                          ↑
                   Cliquez ici pour taper
```

**Options :**
- **Curseur** : Glissez de 0 à 10 mm
- **Saisie** : Tapez n'importe quelle valeur entre 0 et 10
- **Flèches** : Cliquez ▲▼ pour ajuster par pas de 0.5 mm

**Exemples :**
- Tapez `0` pour aucun espacement
- Tapez `1.5` pour 1.5 mm d'espacement
- Tapez `3.2` pour un espacement précis

### 3. Épaisseur (mm)
```
[Label] [===o==========] [3.0]
                          ↑
                   Cliquez ici pour taper
```

**Options :**
- **Curseur** : Glissez de 1 à 10 mm
- **Saisie** : Tapez n'importe quelle valeur entre 1 et 10
- **Flèches** : Cliquez ▲▼ pour ajuster par pas de 0.5 mm

**Exemples :**
- Tapez `2` pour 2 mm d'épaisseur
- Tapez `2.5` pour une épaisseur précise
- Tapez `4.8` pour une valeur exacte

## 💡 Utilisation Pratique

### Méthode 1 : Curseur (rapide)
1. **Déplacez le curseur** approximativement
2. L'aperçu se met à jour en temps réel
3. Parfait pour tester rapidement différentes tailles

### Méthode 2 : Saisie (précis)
1. **Cliquez dans le champ** de valeur
2. **Tapez** la valeur exacte (ex: `28.5`)
3. **Appuyez sur Entrée** ou cliquez ailleurs
4. Le curseur se positionne automatiquement

### Méthode 3 : Flèches (incrémentiel)
1. **Cliquez dans le champ** de valeur
2. **Cliquez sur ▲** pour augmenter
3. **Cliquez sur ▼** pour diminuer
4. Ajustement précis par petits pas

## 💡 Astuces Pro

### Astuce 1 : Valeurs Favorites
Si vous utilisez souvent les mêmes valeurs :
- **30 mm** pour les logos
- **2 mm** d'espacement
- **3 mm** d'épaisseur

→ Tapez directement ces valeurs au clavier !

### Astuce 2 : Décimales
Vous pouvez utiliser des décimales :
- `20.5` mm
- `1.8` mm d'espacement
- `2.3` mm d'épaisseur

### Astuce 3 : Limites
Les valeurs sont automatiquement limitées :
- **Taille** : 5 à 100 mm
- **Espacement** : 0 à 10 mm
- **Épaisseur** : 1 à 10 mm

Si vous tapez `150`, la valeur sera automatiquement ramenée à `100`.

## 📋 Raccourcis Clavier

Dans les champs de saisie :
- **Tab** : Passer au champ suivant
- **Entrée** : Valider la valeur
- **↑** : Augmenter la valeur
- **↓** : Diminuer la valeur
- **Ctrl+A** : Sélectionner tout
- **Ctrl+C** : Copier la valeur
- **Ctrl+V** : Coller une valeur
